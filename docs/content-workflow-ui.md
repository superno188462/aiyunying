# 选题与双平台内容工作台：界面设计

## 用户与目标

内容运营者输入主题即可获得 AI 创作选题，也可添加小红书笔记作为参考；选择一个选题，反复审核公众号长文；确认后生成 3–5 张小红书知识卡片，并导出两平台素材。没有参考笔记时不展示已验证爆款热度的结论。

## 信息架构

沿用现有 React、Ant Design、深色侧边栏和登录体系。在小红书导航中新增“内容策划”入口，路由 `/platforms/xhs/content-workflow`。一个页面内展示任务列表和当前任务的四步流程：热门参考 → 选题 → 文案 → 图片与导出。刷新后按任务 ID 从服务端恢复。

## 页面布局

- 页头：主题输入和参考来源切换。主题策划模式可以不填参考，也可填写 1–5 条笔记的标题、内容、可选链接和互动数据；账号模式保留 PC 账号选择与“获取热门内容”按钮。
- 左侧：历史任务列表，显示主题、当前阶段、更新时间；允许切换任务。
- 右侧：步骤条和当前步骤的主工作区。
  1. 热门参考：笔记卡片列出标题、互动数据、来源链接和采集时间；采集失败允许重试。
  2. 选题：3–5 张候选卡片，包含目标读者、角度、差异点、依据；点击“采用此选题”。
  3. 文案：标题与正文编辑区、版本记录、修改意见输入框、“重新生成”和“确认文案”。
  4. 图片与导出：3–5 张可预览的卡片，逐张可编辑文字并重新渲染；下载 PNG、复制小红书标题/配文、复制公众号正文。

## 状态与交互

- 初始：默认主题策划模式，只要求输入主题；无任务时展示空状态。账号模式才要求选择已绑定账号。
- 加载：按钮禁用并显示进行中的步骤；重复点击不会创建第二个同主题请求。
- 成功：显示最新持久化状态和阶段结果；选择题目、确认文案均有明确成功反馈。
- 待确认：候选题目和文案使用醒目的确认按钮，不自动跳至下一步。
- 可恢复错误：网关、XHS 或生成失败时显示安全的错误信息和重试入口，保留已完成内容。
- 不可恢复错误：账号失效、权限不足时指引前往账号矩阵或重新登录。
- 取消/切换：页面请求使用取消信号或请求序号防止旧响应覆盖；服务端生成任务可在完成后从历史任务恢复。
- 并发：任务带版本号；提交旧版本返回 409 并要求刷新。每个任务同时只运行一个生成动作。
- 校验：主题 2–120 字，修改意见至多 1000 字，文案不能为空；图片张数 3–5。

## 响应式与可访问性

桌面双栏，窄屏改为上下布局。步骤、卡片和按钮可用键盘操作；图片有替代文字，错误由文字提示表达；颜色不作为唯一状态标识。

## API 映射

页面只调用共享 API Client：创建任务、任务列表/详情、采集热门笔记、生成选题、确认选题、生成/修改文案、保存/确认文案、生成/更新图片、下载发布包。服务端根据当前阶段拒绝越级操作，并返回稳定错误码与任务版本号。

## 视觉延续

沿用现有 Ant Design 的卡片、步骤条、表单、通知和深浅色主题。热门笔记与候选题目使用现有内容库卡片密度；文案编辑区保持大块可读空间。
